# MurMur Cloud Terminal

A distributed compute orchestration layer for autonomous AI agents.

MurMur Cloud Terminal is a cloud-native execution environment designed to run, coordinate and monitor AI agents across scalable infrastructure.

## Core Capabilities

- Agent lifecycle management
- Secure goal execution
- Distributed task orchestration
- Real-time telemetry & logging
- WebSocket-based control channel
- Multi-tenant isolation

## Why This Exists

Modern AI agents require:

- Stateless execution
- Secure identity verification
- Scalable compute allocation
- Persistent memory integration

MurMur Cloud Terminal provides the infrastructure layer that makes autonomous systems production-ready.

## Architecture

- API Layer (Fastify / Express)
- Execution Engine
- WebSocket Control Gateway
- Redis Event Bus
- PostgreSQL / Supabase persistence
- Kubernetes-ready deployment

## Status

Phase 1: Agent execution + logging  
Phase 2: Multi-agent coordination  
Phase 3: Distributed Constellation Mesh

## Local Deploy

```bash
npm install
npm run build
npm run start
```

The service starts on `http://localhost:3000` and can be deployed with the same production build artifacts generated by `next build`.

## Statistics & Analysis

- `GET /api/metrics` exposes Prometheus/OpenMetrics counters and gauges.
- `GET /api/analytics?limit=20` returns JSON with aggregate execution stats and recent execution results.
- Use both endpoints to build dashboards and perform later trend analysis.
